# Product Requirement Document

# Project

Team Showcase

---

# Purpose

Create a modern website that introduces a team of approximately ten members.

The website should provide an attractive experience while allowing visitors to quickly learn about every member.

---

# Goals

- Showcase team members
- Display member roles
- Display personal motto
- Provide social media links
- Create an interactive browsing experience
- Mobile friendly

---

# Target Users

- Students
- Organizations
- Communities
- Startup Teams
- Open Source Teams

---

# Functional Requirements

## Hero Section

Contains

- Team name
- Team slogan
- Group photo
- CTA button

---

## About Section

Contains

- Short description
- Team mission
- Team vision

---

## Team Members

Display all members in card format.

Each card contains

- Photo
- Name
- Position

Hover interaction

- Lift animation
- Image zoom
- Show motto
- Show social icons

Click interaction

Open member detail modal.

---

## Member Modal

Contains

- Large photo
- Name
- Position
- Motto
- About
- Skills (optional)
- Social media

---

## Statistics

Display

- Total members
- Total projects
- Achievements
- Years active

---

## Footer

Contains

- Copyright
- Team links
- Contact

---

# Non Functional Requirements

- Responsive
- Accessible
- Fast loading
- Clean animations
- Easy to maintain

---

# Tech Stack

React

Vite

Tailwind CSS

Framer Motion

Lucide React

---

# Data Source

Static JSON file.

No backend.

---

# Success Criteria

- Responsive on desktop/mobile
- Smooth animations
- Easy to add new members
- Lighthouse score above 90
