# Team Showcase

A modern and interactive profile website built with **React + Vite** to introduce a team or community.

The website presents every member through beautiful profile cards with smooth animations, social media links, and personal mottos.

---

## Features

- Responsive design
- Modern landing page
- Team introduction
- Interactive member cards
- Hover animations
- Member detail modal
- Social media links
- Team statistics
- Smooth scrolling animations
- Dark mode (optional)

---

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build production

```bash
npm run build
```

---

## Data

All member information is stored inside

```
src/data/members.js
```

No backend is required.
